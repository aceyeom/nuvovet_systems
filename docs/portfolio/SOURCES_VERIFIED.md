# Sources verified for the portfolio DUR showcase

Verification date: **2026-10-02**. This list matches `frontend/src/portfolio/knowledge/sources.js` one-to-one. A test (`engine/__tests__/knowledge.test.js`) fails if a DOI or PMID in the registry is missing here.

## How each source was checked

- **PubMed records (kind `doi` / `pmid`).** Each DOI was searched on PubMed with the `[doi]` field tag through the PubMed MCP tools (`search_articles`, then `get_article_metadata`). We confirmed the title, journal, year, PMID and DOI, and read the abstract. For open-access articles (PMC), we also read the full text (`get_full_text_article`) where a number we use comes from the body: Bhatti 2015, Acierno 2018, Marks 2018, Keene 2019 and Archer 2014. Records without a DOI on PubMed (MacPhail 1998, Radulovic 1995, Rumbeiha 1995) are cited by PMID only.
- **Product labels (kind `label`).** DailyMed was blocked by this environment's egress proxy, so label statements were confirmed with web searches. The searches returned the DailyMed/FDA, UK VMD or manufacturer labels. Approval numbers (NADA etc.) are deliberately left out.
- **Guideline not indexed on PubMed.** The IRIS staging cut-offs were confirmed by web search of the IRIS site.

A claim is used only if it appears in the abstract, the open-access full text or the label summary listed below. Where the showcase needs a number that no source gives, the code says so instead of inventing one. Two examples:
- The RENAL_ADJUST rule states that the source "does not give a specific factor".
- The Heartgard protocol's 50 mcg/kg upper bound is labelled as this prototype's preventive/anti-parasitic boundary, not a label value (the label gives only a 6 mcg/kg minimum).

## Facts deliberately not sourced (and therefore not shown as facts)

- **ALT.** No single reference interval exists. ALT is recorded and marked "compare with your laboratory".
- **CYP3A metabolism of prednisolone and amlodipine.** It is inferred from human pharmacology, and the finding text says so. For prednisolone the clinical effect (phenobarbital may reduce corticosteroid effect) is cited to Bhatti 2015, so that finding is marked "literature"; amlodipine and maropitant stay "mechanistic".
- **50 mcg/kg macrocyclic-lactone threshold.** It is an engine setting from the build spec. The trace labels it as such, and it sits below the 60 mcg/kg collie safety margin in the label. The Heartgard protocol uses the same value as its upper bound and says it is not a label number.
- **P-gp inhibitor potency.** `pk.pgp.inhibitor` keeps a strong/moderate value for the engine, but no source grades canine P-gp inhibition, so the grade is never shown to users.
- **Lokivetmab.** It was not cited because no source for it was verified in this session.

## Adversarial clinical and citation review (2026-10-02, second pass)

Every DOI/PMID above was re-fetched with `get_article_metadata`; all 46 PubMed records resolve and match title, journal and year. Each claim attached to a source was re-read against the abstract or (for PMC open-access papers) the full text: Archer 2014, Marks 2018, Acierno 2018, Keene 2019 and Bhatti 2015 were re-read in full. Label statements were re-checked by web search because DailyMed and manufacturer sites are blocked by the egress proxy. Corrections made:
